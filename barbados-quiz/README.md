# Barbados 60 & 5 Quizzes

Quizzes and printable activity packs celebrating Barbados' 60 years of Independence and 5 years as a Republic (November 30, 2026).

🔗 Live site: [barbados-quiz.netlify.app](https://barbados-quiz.netlify.app)

| File | What it is |
|---|---|
| `index.html` | Home page linking to both quizzes and both printable packs |
| `toddler-quiz.html` | Tap-and-play quiz for ages 3–5: the flag, the President's flag, colouring the President's flag, colours, St. Michael landmarks, the Coat of Arms, numbers, and decorating an ornament |
| `ages-7-11-quiz.html` | Scored quiz for ages 7–11: 16 questions, plus a bonus round of 5 Bajan sayings picked at random each game |
| `toddler-activity-pack.pdf` | 8-page printable pack for the toddler quiz |
| `ages-7-11-quiz-pack.pdf` | 9-page printable pack: the 16 questions, landmarks, parish matching, Bajan sayings matching, and answer key |

Each HTML page is self-contained. The images are embedded in the page itself, and there's no build step.

## Deploying

The site is hosted on Netlify, on the **barbados-quiz** site.

**If Netlify is linked to this repo:** set the site's **Base directory** to `barbados-quiz`, leave the build command empty, and leave the publish directory empty. Every push to `main` then goes live.

**By drag and drop:**

1. Zip the five files in this folder (not this README), keeping them at the top level of the zip.
2. In Netlify, open the **barbados-quiz** site and go to **Deploys**.
3. Drag the zip into the drag-and-drop box.
